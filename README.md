## 📌 About the Course

This course, created by **Lazy Programmer Inc**, covers deep learning and AI using TensorFlow 2 — Google's powerful machine learning framework.

It starts from basic machine learning concepts and progresses to advanced topics such as:

* Artificial Neural Networks (ANN)
* Convolutional Neural Networks (CNN)
* Recurrent Neural Networks (RNN)
* Natural Language Processing (NLP)
* Generative Adversarial Networks (GANs)
* Reinforcement Learning
* Time Series Forecasting

The course focuses on **hands-on learning** with real-world projects and practical implementation. ([Udemy][1])

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/bsshreesha/Udemy-TensorFlow2.git
cd Udemy-TensorFlow2
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Jupyter Notebook:

```bash
jupyter notebook
```
